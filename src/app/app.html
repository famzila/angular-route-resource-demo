A practical guide to Angular route resources (v22.2, developer preview). Each example is a project screen: load it with its document, show the page while data is still arriving, refresh without leaving the route, or handle errors, redirects, and cancelled requests. Examples

  • Resources: load the project and document together
  • Open the page immediately and show a loading state
  • Keep the user on the current page when a required load fails
  • Show a load error on the page itself
  • Redirect when the project does not exist
  • Keep the current project on screen while the next one loads
  • Refetch when a query parameter changes
  • Cancel the previous request when you move on
